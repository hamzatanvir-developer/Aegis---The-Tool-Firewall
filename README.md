    # Aegis Tool Firewall 🛡️

**Sub-millisecond runtime security firewall for AI agent tool calls.**

Aegis is an inline proxy and function-level decorator that intercepts, inspects, and redacts tool execution payloads generated by LLM agents before they hit production systems.

---

## ⚡ Key Features

* **Sub-Millisecond Interception:** Built using Python function decorators (`@guardrail`) with zero runtime overhead.
* **Destructive Command Blocking:** Stops SQL mutations (`DROP`, `TRUNCATE`) and shell injections (`rm -rf`, piping) before execution.
* **Inline PII & Secret Redaction:** Automatically detects and masks API keys (AWS, OpenAI), Bearer tokens, and sensitive strings.
* **Enterprise Audit Logging:** Logs runtime execution payloads, verdicts (`ALLOW`, `BLOCK`, `REQUIRE_APPROVAL`), and latency directly to PostgreSQL.
* **Zero Trust & Fail-Closed:** Defaults to blocking tool calls if unexpected exceptions occur during evaluation.

## 🚀 Quickstart

```python
from aegis.core import guardrail
from aegis.exceptions import PolicyViolationError

@guardrail
def execute_sql(query: str):
    return f"Executing: {query}"

# 1. Safe query executes normally
execute_sql(query="SELECT * FROM users WHERE id = 1;")

# 2. Destructive query instantly raises PolicyViolationError
try:
    execute_sql(query="DROP TABLE users;")
except PolicyViolationError as e:
    print(f"Blocked by Aegis: {e}")
